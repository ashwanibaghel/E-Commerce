# Baghel Digital Commerce Core

This workspace package contains the commerce runtime used by the Baghel Digital Ecommerce Demo.

The demo has been customized for an electronics storefront with:

- Premium Baghel Digital storefront branding
- INR product pricing
- Cash on Delivery checkout
- Customer account and saved address flows
- Invoice and product support document downloads
- Simple admin dashboard for products and order status handling

Run from the repository root:

```bash
npm run compile
npm run dev
```
